## Completed local browser checks

The integration owner directly observed these flows. They use test records; private source text, résumés, account identity, and credentials are not included here.

- Experience: enter employer, title, year-only start date, Present end date, and an accomplishment inline. One Save creates the section and reusable entry together. Switching Classic to Compact preserves the entered text.
- Education: enter institution, degree, field of study, numeric GPA, month/year start date, and full end date. Saving and reopening preserves the values and date precisions.
- Evidence and Skills: save Skill and Achievement evidence without sources, then select the active Skill in the generated Skills form and save its evidence link.
- Source processing: upload the repository's fictional DOCX and compiled PDF through the browser. Both reach Ready and display the expected extracted text. DOCX preserves repeated passages, accents, and Chinese text. Live AI evidence results are recorded separately under hosted acceptance.
- Fill from evidence: review an achievement for a new Experience entry. A subsequent employer edit makes that review stale and disables Apply. Refreshing preserves the employer edit, inserts the supported accomplishment, and leaves unknown dates and location empty. Saving and reopening preserves all values.
- Custom schemas: adding a self-reference blocks Save with a cycle error and retains the last PDF. Undo restores validity. Create a custom entry with a Recognition field, reference it from Experience, and save the template through automatic approval. Its generated nested form preserves existing data and saves the new custom value. Switching to default fields and back restores that value. A discovered duplicate-choice issue was fixed so field selection lists each loaded template once, using its greatest approved version while retaining pagination and pinned historical content.
- Administration: the default allowance change persists after reload and was restored to 25. Dashboard views contain identities/counts, with backups in Administration. A separately registered ordinary account shows 25 of 25 results and the midnight UTC reset, has an empty workspace, cannot load another account's résumé, and is redirected away from Administration.
- Summary: enter text directly and save once, without manually creating an intermediate block or content record.
- Contact: save an arbitrary labeled link. Preview the section in the actual résumé PDF at the intended position, then insert it.
- Contact lifecycle: Delete then Undo; separately Delete, Restore from Trash, Undo that restoration, and restore again.
- Retained export: delete the saved résumé's reusable Summary and custom template, then reload its review/export page. Document checks remain Passed, its PDF renders, and the retained file is byte-for-byte unchanged (SHA-256 `2fb8b03e709ebda67b56e7bd6375281fa0beceada217e1d12f7a2aad202ca6ca`). Restore the section, template, and a separately deleted source from Trash. PDF comparison used the retained local R2 object; the browser download-event hook timed out, so it is not claimed as download-manager verification.
- Custom template: one Save validates and automatically approves the template, with a real compiled sample PDF.
- Manual job intake: save pasted text with Qualifications and Eligibility separated. Résumé creation remains available.
- Contextual previews: insert Contact, edit Summary before insertion, and insert Experience. A duplicate Contact produces an error while retaining the previous PDF and disabling Add. Returning to Summary preserves its edited text and produces a current preview.
- Export: save the composed résumé, review its real PDF, and export successfully. Unlinked evidence does not create a review gate. The PDF includes the contact link, edited Summary, Experience text, year-only date, and Present date.

These local checks establish manual job intake through export and PDF/DOCX text extraction. Separate [hosted checks](v1.2-hosted-acceptance.md) now establish live pasted-job and wording execution, document export, scoring, and a retained export after deleting/restoring its reusable Summary. Saved-version, onboarding, history, and template-binding language was also reviewed in the browser.
