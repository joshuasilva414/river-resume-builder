## Decisions

- Guide a new account from empty workspace to reviewed PDF without developer assistance. Keep manual use available without AI.
- Preserve the evidence/content hierarchy, immutable revisions, review requirements, and account isolation.
- Use Vercel AI SDK 7 with OpenAI, Anthropic, Google Gemini and OpenRouter provider packages. Effect Schema remains authoritative. BYOK is required for all accounts; ATS scoring remains a separately funded service.
- Save encrypted provider connections, use provider model catalogs, and allow an account default plus a per-action override. No silent connection/model fallback. Retain bounded execution and retry semantics.
- Replace nested creation dialogs with one editor and Back navigation; add ready-to-fill starters for all seven content types.
- Simplify production review to PDF, wording changes, relevant supporting excerpts, and actionable warnings. Full originals remain in Sources. Prompts, raw payloads, LaTeX and technical exports belong in a separate opt-in Advanced tools area.
- Remove ranking acceptance, retaining explicit evidence selection and freshness checks. Keep automatic template checks and a single explained approval action.
- Keep successful PDFs visible during refresh and distinguish empty, pending and failed results. Verify PDF/DOCX source-to-claim reliability.
- Evaluate vector retrieval independently; production indexing is not a release dependency.
- Paper designs precede UI implementation. See [Paper handoff](v1.1-paper.md); status progresses Designed → Implemented → Verified only with evidence.
