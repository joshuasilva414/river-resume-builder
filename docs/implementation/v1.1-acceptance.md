### Failures found and corrected

- **Model discovery:** the screenshot's connection error came from Workers rejecting `redirect: "error"`. Discovery now uses `manual` and rejects redirects without forwarding credentials. An actual workerd reproduction failed before the fix and returned the catalog afterward. This was an application defect, not a Chrome confirmation or proof of an invalid key.
- **Saved-key use:** credential authentication now binds only stable owner/connection/provider/revision fields. Decrypting a loaded database row no longer authenticates unrelated timestamps or ciphertext fields. Saved-key execution and recovery both pass.
- **Default choice:** the optional AI selector accepts explicit `undefined` from UI transport and resolves the saved default. Contract and hosted source checks pass.
- **Source context:** a live response invented an unselected context reference. The output schema now constrains references to exact selected pairs, or an empty array when none were selected. Domain validation blocked the invalid response.
- **Wording citations:** two hosted attempts failed exact-offset validation. The model now selects an indexed exact posting occurrence in its output schema. An actual workerd request and the third hosted attempt pass. Repeated-text and Unicode anchors are covered by a regression test.
- **Scoped ranking:** two attempts referenced background requirements outside the requested scope. The output schema now restricts requirement IDs and exact claim/revision pairs. The third hosted attempt and direct evidence selection pass.
- **Refinement text:** the first candidate copied LaTeX escapes into its intended plain-text fields; text-integrity checks correctly blocked it. Instructions now distinguish document source escaping from visible plain text. The corrected candidate preserved `&` and `%`, passed checks and exported.
- **Review disclosure:** removed raw-input and execution-identity dropdowns from ordinary source, wording, job and duplicate reviews. Template review's blank Extracted text/Report tabs now show plain text and Checks. Refinement review summarizes actual changes and checks. Model-authored explanations can still contain technical wording; this is reduced disclosure, not a guarantee that every generated sentence is jargon-free.
