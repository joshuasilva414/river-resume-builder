# v1.1 retrieval experiment

Recommendation: keep production indexing unchanged for this release. Evaluate relevance ordering before adding Vectorize. The synthetic experiment shows a clear newest-first failure, but is not sufficient evidence for a production semantic search deployment.

The corpus contains 151 fictional claims: 148 eligible claims plus foreign-account, archived, and stale-revision traps. Four queries each have three graded relevant claims and more than 30 incidental keyword matches. Compare the existing FTS-match/newest-first policy, SQLite FTS5 BM25 ordering, and lexical/semantic reciprocal-rank fusion (constant 60, final cap 30). Semantic rankings use live Workers AI `@cf/baai/bge-m3` embeddings and exact cosine similarity computed in the evaluation process. No production data or index was used.

| Retrieval policy | Mean recall at 30 | Mean reciprocal rank |
| --- | ---: | ---: |
| FTS matches, newest first | 0% | 0 |
| FTS relevance | 41.7% | 1 |
| FTS + semantic fusion | 91.7% | 1 |

The combined embedding request covered 155 texts / 22,678 characters in three batches, taking 1,462ms in total (780/450/232ms). This includes initial corpus embedding and is **not** per-query latency. Local lexical queries took 0.081–0.183ms in this single run, excluding hosted D1/network overhead. The provider did not return billed token usage. The model's published unit price was $0.012 per million input tokens on September 6, 2026; exact cost cannot be derived from character count. [Workers AI model documentation](https://developers.cloudflare.com/workers-ai/models/bge-m3/).

The evaluator rejects foreign, archived, and stale revision IDs before fusion, enforces the final cap, and exercises lexical fallback when semantic results are missing or ineligible. These are local algorithm checks, not hosted Vectorize account-isolation guarantees. The exaggerated repeated distractors deliberately test a truncation failure. Results are not a real-world accuracy estimate; the paraphrased accessibility claim still misses the top 30.

Reproduce the measurements without another provider call:

`node scripts/evaluation/retrieval.mjs docs/evaluation/v1.1-semantic-ranks.json`

The retained rankings include scores and batch timings. The fixture module exports `embeddingInput` for a fresh batch through Workers AI's documented embedding endpoint. No key or raw vector is stored in the repository.

Before adoption, run a separately named nonproduction Vectorize index, compare hosted D1/Vectorize latency and actual usage, test filter namespaces and deletion/revision lag, and measure final AI ranking usefulness on a broader labeled corpus. Preserve authoritative D1 ownership/revision/archival checks after retrieval and deterministic lexical fallback. Vectorize storage/query charges are separate from embedding charges. [Vectorize pricing](https://developers.cloudflare.com/vectorize/platform/pricing/).
