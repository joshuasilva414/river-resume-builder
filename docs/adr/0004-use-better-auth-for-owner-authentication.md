# Use Better Auth for owner authentication

The hosted application will use Better Auth for the Owner account instead of delegating browser authentication to Cloudflare Access. V1 supports both GitHub OAuth and an allowlisted email/password flow with verification and password recovery. Authentication messages use a destination-restricted Cloudflare Email Service binding. Sessions are revocable, stored in D1, valid for 30 days, and not duplicated in KV or a cookie session cache. This keeps authentication inside the application boundary and leaves room for future account capabilities without making V1 multi-user. External agents remain separate identities and do not use Owner sessions.
